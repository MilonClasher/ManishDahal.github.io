# Manish Dahal | Portfolio

Static site for GitHub Pages. No build step.

## Add a project photo
1. Save the photo in `images/` (about 800 x 600 px, WebP or JPG).
2. In `index.html`, find the project with an empty photo frame.
3. Remove the comment marks around the `<img>` line in that project.

## Contact form
By default the form opens the visitor's email app.
To receive messages directly, create a free form at formspree.io
and put its URL in `FORM_ENDPOINT` at the top of `script.js`.

## Phone number
In `index.html`, find `PHONE NUMBER`, remove the comment marks, and enter your number.
